# 2. Fontes de Dados

Os dados utilizados neste projeto são dados estruturados de transações financeiras, disponibilizados para fins educacionais, sem informações confidenciais ou pessoais.

## Descrição das Fontes
A base contém registros de transações financeiras realizadas por diferentes meios de pagamento, incluindo cartão de crédito e boleto bancário.

## Tipo de Dados
- Dados estruturados
- Variáveis numéricas e categóricas
- Informações sobre valor da transação, meio de pagamento e status

## Método de Coleta
- Download direto do arquivo de dados
- Importação para Google Sheets
- Exploração e análise por meio de SQL
