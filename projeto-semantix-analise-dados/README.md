# Projeto de Análise de Dados — Parceria Semantix

Este projeto foi desenvolvido como parte do curso de Análise de Dados da EBAC, em parceria com a Semantix.

## Objetivo
Analisar dados de transações financeiras para identificar padrões de inadimplência, falhas em pagamentos e desempenho dos meios de pagamento, apoiando a tomada de decisão baseada em dados.

## Problema
A inadimplência e as falhas em transações financeiras impactam diretamente a receita, a eficiência operacional e a experiência do cliente. A análise de dados permite identificar gargalos e oportunidades de melhoria nos meios de pagamento.

## Fontes de Dados
Os dados utilizados são dados estruturados de transações financeiras, disponibilizados para fins educacionais e sem informações confidenciais.

## Metodologia
- Coleta de dados via arquivo CSV
- Exploração e análise utilizando SQL
- Análise exploratória de dados (EDA)
- Construção de dashboard no Looker Studio

## Principais Insights
- O cartão de crédito concentra a maior parte do valor total das transações aprovadas.
- O boleto bancário apresenta maior incidência de não pagamento.
- Transações com erro impactam negativamente a eficiência operacional.

## Visualização de Dados
O projeto conta com um dashboard interativo desenvolvido no Looker Studio, apresentando indicadores e gráficos sobre meios de pagamento e status das transações.

O link para o dashboard está disponível na pasta `/dashboard`.
